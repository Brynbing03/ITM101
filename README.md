# Scheduling Web Application

## About the Project

Our project is a scheduling and daily planner web application. It will allow users to add activities, events, and tasks to their schedule so they can keep track of everything they have going on.

Users will also be able to set personal goals and track their progress.

We want the application to be more than just a basic calendar. Along with scheduling events, we want to eventually add features that help users better manage their time, such as automatically scheduling study time, creating recurring events, and moving unfinished tasks to another available time.

## Problem We Are Solving

Scheduling out your day and keeping track of everything you need to do can be difficult, especially when balancing school, work, appointments, goals, and other responsibilities.

Our application will give users one place to organize their schedule, tasks, and personal goals instead of having everything in different places.

## Features

- Goal tracker
- Basic calendar
- Weekly calendar
- Create, edit, and delete events
- Auto schedule study time
- Recurring events in the calendar
- Mark events and tasks as complete
- Shareable schedules
- Automatically shift unfinished events to another available time

## Technology

For the front end, we plan to use:

- HTML
- CSS
- JavaScript

For the cloud portion of the project, we are considering **Firebase**. We could use Firebase Authentication for user accounts and Firestore to store schedules, activities, events, and goals in the cloud.

AWS could also be used, but Firebase may be simpler for our project because it provides many of the services we need in one place.

## Project Viability

We believe this project is realistic for us to complete during the semester.

We can start with the most important features, such as:

- Creating, editing, and deleting events
- Displaying events on a calendar
- Creating and tracking personal goals

Once the basic features are working, we can work on the more advanced features if we have enough time.

## Overall Goal

Our goal is to create a useful scheduling application that uses cloud technology and helps users keep their schedules, tasks, and goals organized in one place.
